# Info

First planned native utility.

Initial scope:

- Exec version/revision
- DOS version/revision when available
- Chip/Fast/total free memory
- largest free memory blocks where safely obtainable
- basic machine-visible system information derived using AmigaOS 1.2-compatible APIs

The first implementation should stay deliberately conservative. It will be used to qualify the compiler, startup code, ABI assumptions, and 1.2 runtime.
