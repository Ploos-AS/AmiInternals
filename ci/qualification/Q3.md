## Q3.1 — Resources

PASS requires:

- starts and exits normally with RC 0;
- identifies `Resources 0.1`;
- prints the `Name` header;
- traverses the classic Exec `ResourceList` without Guru, hang, loop or corrupt output;
- resource names, when present, are printable and structurally plausible for the booted AmigaOS 1.2 environment;
- an empty resource list is valid if that is what the minimal boot exposes;
- any implementation traversal cap is reported rather than overrunning the fixed snapshot.

This test is evidence for the implementation's assumptions about the AmigaOS 1.2 Exec resource list and node layout.

## Q3.2 — Residents

PASS requires:

- starts and exits normally with RC 0;
- identifies `Residents 0.1`;
- prints the `Ver Type Pri Name` header;
- traverses `ExecBase->ResModules` without Guru, hang, loop or corrupt output;
- returned resident entries have structurally plausible numeric version/type/priority fields and printable names;
- invalid resident entries, if encountered, are handled explicitly rather than dereferenced blindly;
- any implementation traversal cap is reported rather than overrunning the fixed snapshot.

At least one resident is normally expected on a booted classic system. Do not hard-code a modern resident list as the oracle.
