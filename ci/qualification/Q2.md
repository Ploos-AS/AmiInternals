# Q2 — M1 batch 2: Ports, Libs, Devices

Status: **READY FOR LOCAL QUALIFICATION**

Q2 reuses the proven Q1 real-classic harness and the same hard gate:

- A500-class / Motorola 68000 / OCS PAL
- 512 KiB Chip RAM, no Fast/Slow RAM
- genuine Kickstart 1.2
- matching Workbench/AmigaDOS 1.2
- no FPU, no JIT, real CPU speed
- visible FS-UAE session
- exact host-built binaries copied to a private writable copy of the verified Workbench disk
- AROS remains supporting smoke/regression evidence only

Do not modify or distribute the ROM or Workbench media. Preserve binary SHA-256, emulator configuration, complete guest output, return code/status evidence, FS-UAE log and screenshot for each tool. Stop at the first real compatibility failure.

## Build gate

Build only the Q2 tools with the same AmigaOS 1.2-compatible startup/toolchain policy established by Q1. Do not raise the minimum OS or silently substitute a newer startup/runtime to make a tool pass.

The exact binaries entering the guest must be hash-checked before qualification and recorded in the evidence.

## Q2.1 — Ports

PASS requires:

- starts and exits normally with RC 0;
- identifies `Ports 0.1`;
- traverses the classic Exec public `PortList` without Guru, hang, loop or corrupt output;
- printed port names are structurally plausible for the booted AmigaOS 1.2 environment;
- empty/unnamed entries are handled safely according to the implementation contract;
- any implementation traversal cap is reported rather than overrunning the snapshot.

This test is evidence for the implementation's assumptions about the AmigaOS 1.2 Exec public message-port list and node layout.

## Q2.2 — Libs

PASS requires:

- starts and exits normally with RC 0;
- identifies `Libs 0.1`;
- traverses the classic Exec `LibList` without Guru, hang, loop or corrupt output;
- library names and version/revision values are structurally plausible for AmigaOS 1.2;
- no dependency on a library introduced after AmigaOS 1.2 is required merely to start or enumerate;
- any implementation traversal cap is reported safely.

At minimum, the result should be consistent with core libraries expected to be present in the actually booted 1.2 environment. Do not hard-code a modern library list as the oracle.

## Q2.3 — Devices

PASS requires:

- starts and exits normally with RC 0;
- identifies `Devices 0.1`;
- traverses the classic Exec `DeviceList` without Guru, hang, loop or corrupt output;
- device names and version/revision values are structurally plausible for the booted AmigaOS 1.2 environment;
- no device is opened or mutated merely for enumeration unless the existing documented implementation explicitly requires it;
- any implementation traversal cap is reported safely.

This test is evidence for the implementation's assumptions about the AmigaOS 1.2 Exec device list and library/device node layout.
